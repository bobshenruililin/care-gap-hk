# The Care Gap (Hong Kong)

Spatial public-health analysis and LaTeX paper on district-level foreign domestic helper (FDH) mitigation of old-age dependency in Hong Kong.

## Repository layout

```
care-gap-hk/
├── analysis/
│   ├── build_dataset.py    # Assemble district_master.csv from raw sources
│   └── run_analysis.py     # OLS, spatial Moran, figures, JSON results
├── data/
│   ├── raw/                # C&SD, SWD, and API extracts
│   └── processed/          # district_master.csv, district_results.csv, analysis_results.json
├── figures/                # PNG outputs (also linked from paper/figures/)
├── paper/
│   ├── care_gap.tex        # Manuscript (compile from this directory)
│   └── figures/            # Symlink → ../figures
└── README.md
```

## Rebuild analysis

**Requirements:** Python 3.10+, `pandas`, `numpy`, `scipy`, `statsmodels`, `matplotlib`. Optional: `openpyxl` for SWD 2026 Excel parsing.

```bash
cd care-gap-hk

# 1. Build merged district dataset
python3 analysis/build_dataset.py

# 2. Run regressions, Moran's I, bootstrap/LOOCV, and write figures
python3 analysis/run_analysis.py
```

**Outputs**

| Path | Description |
|------|-------------|
| `data/processed/district_master.csv` | 18-district analysis dataset |
| `data/processed/district_results.csv` | CDRS, quadrants, residuals, stress metrics |
| `data/processed/analysis_results.json` | Model coefficients and diagnostics |
| `figures/fig_*.png` | AV plot, temporal bridge, unpaid care, quadrant, residuals |

Raw inputs are documented in `data/processed/dataset_meta.json`. If Excel files under `data/raw/` are missing, `build_dataset.py` falls back to embedded SWD capacity totals.

## Compile paper

From the `paper/` directory (so `figures/` resolves correctly):

```bash
cd paper
# Prefer tectonic if available (used in this repo):
tectonic care_gap.tex

# Or classic TeX Live / MacTeX:
pdflatex care_gap.tex
pdflatex care_gap.tex   # second pass for references
```

Or with `latexmk`:

```bash
cd paper
latexmk -pdf care_gap.tex
```

**Requirements:** A LaTeX distribution with `article`, `geometry`, `booktabs`, `graphicx`, `hyperref`, `setspace`, `amsmath`, `siunitx`, `float`, `caption`, `subcaption`, `longtable`, `enumitem`, `threeparttable`, `natbib`.

The compiled PDF is written to `paper/care_gap.pdf` (15 pages in the July 2026 revision).

Figures are generated by `run_analysis.py`; re-run analysis before compiling if the dataset changes.
